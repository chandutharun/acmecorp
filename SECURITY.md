# 🔒 Security Policy

## ⚠️ This Project is Intentionally Vulnerable

AcmeCorp Internal Assistant is a **deliberately insecure lab environment** designed for:
- Prompt-injection testing
- LLM agent security research
- Red-team training

**This is NOT a real chatbot. Do not deploy in production.**

## 🛡️ Reporting Vulnerabilities in REAL Systems

If you discover vulnerabilities in **actual LLM agents** (not this lab), please:
1. Do not exploit them for malicious purposes
2. Follow responsible disclosure
3. Contact the system owner directly

## 🎯 How to Use This Project Responsibly

- ✅ Use in isolated lab environments only
- ✅ Never connect to real internal services/APIs
- ✅ Never use against systems you don't own
- ✅ Follow local laws and regulations
- ✅ Share findings for educational purposes only

## 🚫 Prohibited Uses

- ❌ Attacking production systems
- ❌ Stealing real data via prompt injection
- ❌ Malicious AI exploitation
- ❌ Commercial exploitation of vulnerabilities
